## 运行方式
1. 用 IntelliJ IDEA 打开本目录
2. IDEA 自动识别 Maven 项目
3. 浏览器打开 `src/main/resources/static/index.html` 预览

## 技术栈
- 后端：Java 17 + Maven
- 前端：纯 HTML + CSS + JavaScript（无外部依赖）
- 存储：localStorage（前端持久化）
